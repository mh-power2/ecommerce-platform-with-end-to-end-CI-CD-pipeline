# E-Commerce Platform

Full-stack e-commerce application demonstrating an end-to-end
DevOps and DevSecOps delivery pipeline.

## Technology Stack

- Frontend: Angular
- Backend: Spring Boot
- Database: PostgreSQL
- CI: Jenkins
- Container Registry: Docker Hub
- Deployment: OpenShift and Helm
- GitOps: Argo CD
- Infrastructure: Terraform and Ansible
- Security: SonarQube, Semgrep, OWASP Dependency-Check, Trivy
- Observability: Prometheus, Grafana, Loki, Alertmanager
